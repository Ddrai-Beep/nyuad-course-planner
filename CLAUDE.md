# NYUAD Course Planner: notes for Claude

Static web app (GitHub Pages, no build step) that reads an NYUAD ARC 4-year plan and checks it against all 26 NYUAD majors (Political Science with 4 tracks; others with their concentrations/tracks), the minors, the Core, gen ed and 128 credits. No AI is used in the checks. The rules are plain data.

- `src/parser.js`: reads the ARC template grid (term anchors → "Course" header → rows). Hidden rows are skipped.
- `src/engine.js`: requirement matching (bipartite) and policy rules: Pass/Fail exclusion with a Spring 2026 exception, minimum grade C, and Core competency courses not double-counting with the major or minor.
- `src/app.js`: UI. Sections: tracks → what you still need (one row per course slot) → counts for both → add-a-minor (ranked) → registration list (sidebar) → plan table laid out like the template.
- `data/programs.json`: requirements and policy. `majors[0]` is Political Science (hand-maintained); every other major plus the Art History minor is generated by `scripts/build_majors.py` (NYUAD Bulletin 2026–27). Edit that script, then run `python3 scripts/build_majors.py && python3 scripts/build_catalog.py scripts/crossover.json data/catalog.json`. The major comes from the plan's "Major(s)" line unless the user picks one. `data/catalog.json` is built by `scripts/build_catalog.py` from `scripts/crossover.json` and `scripts/core.txt`. `data/offerings.json` lists courses offered per term (Jensen's PS guide).
- `data/my-plan.csv`: the owner's plan, loaded by default (`DEFAULT_PLAN` in `config.js`).
- `worker/`: optional Cloudflare Worker + D1 for shared "is it running in Albert?" votes and Google Sheets proxying. Not deployed: the owner chose to keep reports in each browser's local storage.

Sources: NYUAD Bulletin (2026–27 program pages); "Political Science Courses — Spring 2027" (J. Jensen, 26 Oct 2026); NYUAD Student Portal (Revised Requirements for Graduation; Spring 2026 Grading Policies + FAQs).

Owner preferences: concise, direct; minimal visual clutter (neutral palette, dark grey header, light yellow background, 2px borders, no purple). Ask before changing anything outside this repo.

Test locally: `python3 -m http.server` from the repo root, then open http://localhost:8000.

Rule clauses also support `minNum`/`maxNum` (exact course number, e.g. Foundations of Science ranges). A requirement can set `credits` per slot (default 4) for the electives estimate.
